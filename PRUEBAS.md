# Pruebas del sistema de préstamos

## Pruebas funcionales

1. Inventario: se verifica la visualización de los 8 equipos.
2. Búsqueda: se comprueba el filtro por nombre.
3. Categorías: se comprueba el filtro de equipos por categoría.
4. Validación: se muestran errores cuando los datos son incorrectos.
5. Registro: se verifica que un préstamo quede almacenado en JSON Server.
6. Disponibilidad: un equipo prestado no permite nuevos préstamos.
7. Devolución: al devolver un equipo, vuelve a estar disponible.
8. Vencimiento: los préstamos vencidos se resaltan en rojo.
9. Persistencia: los registros se conservan después de actualizar la página.
10. Error de API: se muestra un mensaje y el botón Reintentar.

## Tecnologías utilizadas

- React
- TypeScript
- Vite
- JSON Server

## Evidencias

Las capturas de las pruebas se encuentran en el informe de la Tarea 4.
